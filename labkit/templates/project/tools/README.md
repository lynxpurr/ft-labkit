# tools/ — run 脚本谱系与评测脚本约定

## run 脚本纪律

- 改参数改 spec 重新生成，勿手改生成物（spec 入库：一个 run 一个 spec）
- 头注必须写明"与母版只差什么"（单变量纪律）
- 脚本自带门：未知档/臂大声失败；幂等跳过（末步 ckpt 存在才算完成）；
  GPU free < NEED 拒跑；后台显存采样器；跑完核对参数快照与末步 ckpt
- NEED 取实测峰值 + 余量，不乐观估计

## 评测脚本（判分器）

- 入口固定在 `tools/`（命名自定，全仓一致）
- 评测器先行：跑模型列之前，金标过判分器须得已知满分，否则禁跑模型
- 阴性对照：判分器对"必须判错"的篡改样本（幅值/符号/错集）必须判错
  （可直接用 `labkit.gates` 的 `gold_gate` / `negative_controls` / `checks_gate`）
- 判分口径改动 → 必须重过自检门 + 阴性对照，且在 PLAN 记口径变更
- 证据只增不改：产物写定即冻结，口径修订走 rejudge 落新文件
  （`labkit.evidence.write_new` 对已存在产物拒写）

## 训练前对拍（模板/数据形态）

- 首次训练前：核对训练框架实效编码与官方模板一致（文本逐字 + 掩码边界）
- 框架升级后：重跑对拍再信任任何命令形态
